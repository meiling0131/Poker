## 来历

最初的版本有发牌引擎、六个机器人、真筹码牌桌、练习模式和好友房间。**Sicheng Li** 在 `810bd62` fork 了它（[sudo-sc/merlin-poker](https://github.com/sudo-sc/merlin-poker)），让钱在游戏里变成真的：余额、每一笔下注和派彩都记在服务器的数据库里，每天午夜结算并更新排行榜。他还重新设计了大厅和牌桌，加了音效。他的 fork 在 `50fe9b8` 合并回来，原版的一些功能也随之恢复。下面分别列出改了什么、加了什么、保留了原来的什么、去掉了什么，以及还没做完的部分。

### 改动

- **正常模式在服务器上进行。** 以前和机器人打是在你的浏览器里发牌；现在每位玩家在 Verve 服务器（Cloudflare Durable Object）上有自己的牌桌，由服务器发牌、跑机器人、记录一切。练习模式仍在浏览器里。
- **钱。** 以前每日 1,000 的额度记在浏览器里；现在每位玩家在数据库里有真实余额：每天（美东时间）从 1,000 开始，每次买入和取出都由服务器核对。
- **盲注。** 填盲注的输入框换成三张桌：1/2 最低买入 200，2/5 最低 500，5/10 最低 1,000。余额不够的那一档会变灰。
- **买入和取出。** 固定的「买一手 +200 / 退一手 −200」换成一个银行面板，滑杆按最低买入的整数倍调整。不在牌局里就立即执行，否则等你弃牌或这一手结束后执行。
- **下注。** 2×2 四个按钮：Call 和 Raise 选好筹码，Bet 推出去，Fold 弃牌。Raise 打开滑杆，两端是 Min. 和 All in，下面是 1/3 Pot、1/2 Pot、2/3 Pot、Pot 四档预设和 Custom（点金额直接输入）。选出的筹码比要下的多时（买入的筹码都是 25），Bet 只下要下的数，多出来的找零退回。提前操作（过牌/弃牌、过牌、跟任何注）是按钮。
- **筹码。** 买入的筹码都是 25；只有打开「自动整理筹码」才会重新理筹码。
- **一手结束。** 正常和练习牌桌会停在「继续游戏」或「退出牌桌」。结果一直留在牌桌中间，直到下一手开始。退出时如果还在牌局里就先弃牌，再把桌上的筹码换回余额。
- **机器人。** 每个机器人有固定的 id，显示的名字来自数据库。每张牌桌都有每个机器人的一份副本，副本向银行买筹码。
- **牌桌。** 名字旁边用 D、S、B 标出庄家、小盲和大盲。每次行动有 45 秒倒计时圈，打牌时会显示你的牌型。牌一张一张地发，机器人等所有牌落定才行动。
- **玩家资料卡。** 点座位打开和大厅「查看数据」一样的统计弹窗。
- **大厅。** 赌场绿背景、大字余额、名字按钮、滚动排行榜、盲注卡片和扁平按钮。
- **音效。** 原来合成的提示音换成音效文件：轮到你、选择跑几次、每个动作、每发一张牌、每张公共牌、派彩，以及银行操作完成。

### 新增

- **不用注册的玩家身份。** 浏览器保存一个随机 id 和一个密钥 token，服务器只存 token 的哈希。留下名字就能玩，名字可以改一次，也可以在「设置」里清除账号。
- **数据库（Cloudflare D1）。** 有这些表：
  - `players`：当天的玩家和余额。
  - `transactions`：每一笔买入、取出、下注和派彩的账本，所有余额都以它为准。
  - `games`：每位玩家每手一行。
  - `stats`：每位玩家当天的汇总，含 VPIP、PFR、偷盲、3-bet、WSD、WWSF 比率。
  - `leaderboard`：保存下来的最佳。

  详见 [DATABASE.md](DATABASE.md)。
- **排行榜。** 「今日最佳」是实时的：当天打过至少一手的玩家，按余额加桌上筹码排名。「昨日最佳」「本周最佳」「本月最佳」「历史最佳」在午夜保存。并列时先比钱，再比最大一次赢池，再比赢的手数占比，最后随机。
- **查看数据。** 你当天的数据：手数、赢的手数、最大赢池（含五张牌和牌型），以及七个比率，每个都有解释。
- **每天的结算。**
  - **美东 23:55：** 不再开新的一手，各牌桌把人送回大厅。
  - **00:00：** 还在进行的一手算超时，会收到提示。
  - **00:05：** 仍未结束的超时牌局作废，所有下注退回。
  - **00:06：** 保存排行榜，删除前一天的数据。

  每到新的一天，大家都从 1,000 重新开始。
- **设置。** 「游戏音效」开关所有声音；「机器人速度」有较慢、中等（默认）、较快；「牌桌」选一楼或二楼。
- **开发工具。** `/d1` 是浏览本地数据库的页面，`/audit` 用账本核对每个余额。两者只在你自己的电脑上可用。
- **测试。** 覆盖服务器、钱、数据库写入、每天的结算、排行榜、音效和你的下注按钮，共 86 个。

### 保留下来的原有功能

这些在 fork 里被去掉了，合并后又加了回来：

- **好友模式。** 大厅的按钮打开现在有人在的房间列表：点一个就能进，有密码再填密码。也可以输入房间号加入，或者创建房间（不填房间号就随机），密码可填可不填；新房间用大厅里选的盲注。你用自己留的名字玩。还没留名字就打开邀请链接，会先请你留名字，然后直接进房间。房间里的「记录」页有邀请链接、玩家列表（房主可以请人离开）和账本。
- **弃牌和全下的确认。** 点 Fold，或者点会把全部筹码推进去的 Bet，按钮会变成「取消」和「确认 Fold / 确认 All in」。其他操作直接生效。
- **下注预设。** 1/3 Pot、1/2 Pot、2/3 Pot、Pot 和 Custom，现在放在加注滑杆上。
- **二楼。** 「设置 → 牌桌」可以选一楼会议室（胡桃木长桌、千鸟格扶手椅）或二楼休息区（深色石面方桌、皮沙发）。
- **机器人的性格。** 点机器人的座位，统计上方会显示它的头像和打法。
- **每次推到 `main` 自动部署**，通过 GitHub Actions（见 [DEPLOY.md](DEPLOY.md)）。

### 去掉的

- **自定义盲注。** 换成三档盲注。
- **浏览器里的每日额度。** 换成服务器上的余额。
- **换座位（和 TA 换座位）。** 可以借换座位躲盲注。
- **房主重置牌桌。** 会把所有人的筹码一起清零。
- **跟注、过牌和普通下注的确认。** 只有弃牌和全下还会再问一次。
- **「整理」按钮。** 换成「自动整理筹码」开关。
- **牌桌顶栏的额外按钮。** 「主页」按钮和设置菜单去掉了，牌型提示一直开着。
- **输赢提示条。** 「这把 +N / −N」和输光的提示去掉了。
- **GitHub Pages 副本上的联机。** 不是从 Worker 打开的副本只能玩练习模式，除非网址加上 `?server=<Worker 的地址>`。

### 还没做完的

- 好友房间里**玩家之间转账**还没做。
- **「记录」页**只在好友房间里开放；其他地方的统计通过「查看数据」看。
- **关于。** 这个按钮还是占位的。
- **已知问题：**
  - 一手进行中，「今日最佳」算的是玩家这一手开始前的筹码。
  - 极少数服务器重启时，一手牌的筹码记录可能写两遍，修复已在计划中。
  - 牌局记录里不管买入、取出多少，都还写成「买一手 / 退一手」。
  - 音效文件的音量还没有统一。

## 怎么玩

1. 打开游戏（部署好的 Worker 网址，本地运行时是 http://127.0.0.1:8787），点名字按钮留下名字。你当天的余额是 1,000。
2. 选一档盲注，点**进入游戏**。银行面板会打开：拖到想买的数，点**买入**。**练习模式**给的是假筹码，不会记录。
3. 和朋友玩：点**好友模式**，从列表里选一个房间，或者输入房间号点**加入房间**或**创建房间**。把「记录」页里的链接发给朋友。
4. 轮到你时，点筹码，或者用 **Call / Raise** 选好数，再点 **Bet** 推出去。**Fold** 弃牌。弃牌和全下会再确认一次。
5. 一手结束后，点**继续游戏**打下一手，或者点**退出牌桌**离开。离开时桌上的筹码回到余额。好友房间会自动发下一手。
6. 在大厅点自己的名字看**查看数据**，在牌桌上点别人的座位看他的数据。

每天在美东时间午夜结算。第二天重新留名字，从 1,000 开始。

## 开发说明

单页应用，原生 ES 模块，没有构建步骤。网页、游戏服务器和数据库是同一个 Cloudflare Worker。

### 目录

```

css/                样式，按编号顺序加载，后面的会覆盖前面的

  settings.js       盲注、正常/练习模式、牌桌楼层
  state.js          共享的运行状态，写入用 setX()；界面通过 view 钩子注册重画函数
  player.js         从服务器读写玩家记录、统计、机器人名字和排行榜
  cards.js          牌、洗牌、比牌型、胜率估算        ← 纯逻辑，有测试
  chips.js          筹码：精确付款、找零、整理          ← 纯逻辑，有测试
  pots.js           主池和边池                          ← 纯逻辑，有测试
  table.js          牌桌状态上的查询和小操作

  bots.js           机器人策略
  stats.js          每位玩家的计数，以及一手牌写入的 games 行
  talk.js           头像、机器人台词、表情
  fx.js             音效、彩带、屏幕常亮

  net.js            服务器客户端：用 WebSocket 实现 doc/onSnapshot 接口；好友房间列表
  actions.js        你的操作：Call、加注滑杆和预设、带找零的 Bet、弃牌和全下的确认、银行面板、自动整理
```

### 本地运行

```
npm install
npm run dev          # 打包 dist/ 并在本地运行 Worker：http://127.0.0.1:8787
npm run serve        # 只有网页（只能练习）：http://localhost:8000
```

`npm run dev` 用的是本地数据库。先执行一次 `npx wrangler d1 migrations apply verve --local` 建表。在 `.dev.vars` 文件里写上 `LOCAL_DEV=1` 可以打开 `/d1` 和 `/audit`。要手动跑午夜任务，打开 `http://127.0.0.1:8787/__scheduled?cron=*+*+*+*+*`。

### 改完代码之后

```
npm run stamp        # 更新 index.html 里的版本号（每次改 js 或 css 都要跑）
npm run check        # eslint + 测试；import map 没更新也会报错
```

推到 `main` 就会部署：`.github/workflows/deploy.yml` 先跑检查，再执行新的数据库迁移，然后部署 Worker。需要仓库 Secret `CLOUDFLARE_API_TOKEN`：来自 `wrangler.jsonc` 里那个 Cloudflare 账号的令牌，权限要有 Workers Scripts: Edit 和 D1: Edit。这一点和其他部署方式见 [DEPLOY.md](DEPLOY.md)。

### 服务器接口

| 路由 | 用途 |
| --- | --- |
| `/solo?uid&token&sb&bb`（WebSocket） | 你在这一档盲注的正常牌桌 |
| `/room/<房间号>`（WebSocket） | 好友房间 |
| `POST /player/get`、`/player/set`、`/player/stats` | 你的记录、名字、统计（带 token） |
| `GET /stats?id=` | 任何人当天的统计（资料卡用） |
| `GET /leaderboard` | 今日实时，以及昨日、本周、本月、历史 |
| `GET /bots` | 机器人的 id 和名字 |
| `GET /rooms` | 好友房间列表 |
| `GET /d1`、`GET /audit` | 只在本地：浏览数据库、对账 |

在牌桌的连接上，服务器发 `{t:'table',S}`（你的两张底牌在 `S.mine` 里）、`{t:'seat',doc}`、`{t:'money',…}` 和 `{t:'closed'}`。浏览器发 `{t:'seat',…}`、`{t:'money',delta}`、`{t:'leave'}`，以及房主的 `{t:'cmd',name,args}`：next、speed、clearstats、approve、kick、unkick。

加入好友房间连 `/room/<房间号>?uid&token`；建房再加 `&create=1&sb&bb`，有密码再加 `&pw=`（浏览器里先算好的 `verve:<房间号>:<密码>` 的 SHA-256）。进不去时服务器先发 `{t:'error',code}`：`password`、`taken`、`noroom`、`identity` 或 `closing`。
